# AI 101 Academy — Personal Portfolio Website

## Project Overview

Build a professional, responsive personal website using VS Code, OpenAI Codex, and GitHub.

This project demonstrates AI-assisted software development, including requirements planning, agent instructions, GitHub Issues, testing, commits, pull requests, and human approval.

## Project Goals

- Create a professional online presence
- Showcase verified professional experience
- Highlight selected projects and achievements
- Link to a public LinkedIn profile
- Demonstrate a structured AI development workflow

## Website Sections

1. Home — Professional headline and introduction
2. About — Biography based on approved source material
3. Experience — Career history and accomplishments
4. Projects — Selected work and achievements
5. Contact — LinkedIn and approved contact methods

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- VS Code with OpenAI Codex
- GitHub for version control and Issues
- GitHub Pages for deployment

## Content Sources

The website's professional content must follow `references/PROFILE.md`.

The current resume at `references/resume.pdf` is the primary factual source for experience, education, skills, and accomplishments.

The LinkedIn URL is defined in `references/PROFILE.md`.

Private reference documents must not be committed or published.

## Development Workflow

1. Review project requirements and approved sources.
2. Identify the current GitHub Issue.
3. Create an implementation plan.
4. Obtain approval to implement.
5. Use Codex to develop the feature.
6. Test and review the changes.
7. Update `TASKS.md`.
8. Request approval before committing.
9. Request separate approval before pushing.
10. Request approval before opening a pull request.
11. Review the pull request and obtain merge approval.
12. Update Issue status and identify the next task.

## GitHub Rules

- Use GitHub Issues for feature tracking.
- Use focused branches and commits.
- Do not commit, push, open pull requests, or merge without explicit approval.
- Follow `AGENTS.md` for the detailed workflow.
- Respect repository branch protections.

## Getting Started

1. Open the repository in VS Code.
2. Ensure Codex is configured.
3. Place approved private source files in `references/`.
4. Review `references/PROFILE.md`.
5. Ask Codex to read the project documents.
6. Review its implementation plan.
7. Approve the first Issue for implementation.

## Deployment

Use GitHub Pages for the approved static website.

Before publishing, verify that no private documents or confidential information are included.
