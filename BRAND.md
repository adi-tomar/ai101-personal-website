# Personal Website — Brand Guidelines

## Brand Personality

The website should feel:

- Professional
- Modern
- Confident
- Approachable
- Clean and uncluttered

Avoid flashy effects, unnecessary decoration,
and overly corporate language.

## Visual Direction

Use a minimalist, contemporary portfolio style.

The website should prioritize readability,
clear hierarchy, and generous whitespace.

## Color Palette

Primary Blue: #2563EB
Dark Navy: #0F172A
Main Text: #1F2937
Secondary Text: #64748B
Background: #FFFFFF
Alternate Background: #F8FAFC
Border: #E2E8F0

## Typography

Preferred font: Inter

Fallback:
Arial, Helvetica, sans-serif

### Typography Hierarchy

- Main headline: Large and bold
- Section headings: Clear and prominent
- Subheadings: Medium weight
- Body text: Comfortable reading size
- Captions: Smaller and subdued

## Layout

- Maximum content width: 1100px
- Responsive layout
- Consistent spacing between sections
- Clear navigation
- Rounded cards with subtle borders
- Minimal use of shadows

## Homepage Design

Hero section should contain:

- Name
- Professional headline
- Short introduction
- View Projects button
- LinkedIn button
- Optional profile photograph

## Experience Section

Use a clean professional timeline or cards.

Include:

- Company
- Position
- Dates
- Concise accomplishments

Do not invent missing information.

## Projects Section

Use responsive cards with:

- Project title
- Short description
- Key outcomes
- Optional image or link

## Contact Section

Include:

- LinkedIn profile link
- Optional approved email address
- Short invitation to connect

## Writing Style

- Clear and direct
- Professional but conversational
- Avoid exaggerated claims
- Prefer concise paragraphs
- Use specific achievements when verified
- Avoid generic AI-generated buzzwords

## Accessibility

- Maintain readable contrast
- Use semantic HTML
- Provide keyboard-accessible navigation
- Include visible focus indicators
- Use descriptive link text
- Provide alternative text for meaningful images

## Responsive Design

Desktop: Spacious multi-column layouts
Tablet: Reduced spacing and flexible columns
Mobile: Single-column layout with readable text

## Design Consistency

All new pages and components must follow
these guidelines unless explicitly changed.
